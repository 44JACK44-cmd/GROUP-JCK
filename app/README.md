# App móvil Gas Reparto

App Flutter para administradores y repartidores. Ver el README principal para ejecutarla.

```
lib/
  core/       configuración, tema, red (Dio + JWT), almacenamiento seguro, router
  features/   módulos por funcionalidad (auth, home, reparto, mas, ...)
              cada uno con data/ domain/ presentation/
  shared/     widgets reutilizables (PrimaryButton, StatusBadge, EmptyState...)
```
